OpenTag Brand Kit
Production vector adaptation of your selected artwork.

START HERE
Open BRAND-GUIDE.html for the visual guide and asset browser.
Use 01-logos/app-icons/opentag-app-icon-color.svg as the primary vector master.
Use 01-logos/app-icons/opentag-app-icon-color-4096.png for a large transparent PNG.
Every logo and banner is its own file. Light/dark filenames indicate the intended
background theme. SVG wordmarks contain outlined lettering and need no fonts.

USAGE
Prefer color icon and color wordmark for product and marketing surfaces.
Use the flat icon or monochrome mark at small sizes. The 16–32 px universal icons
use the flat master to preserve readability. Use a white logo on dark surfaces
and an ink logo on light surfaces. Use the black transparent mark as a macOS
template/tray icon and let the app platform tint it.
Keep at least 12% of the icon width as clear space around an isolated icon;
keep approximately one capital-O height around a standalone wordmark.
Preserve the aspect ratio, five audio bars, punched hole, and OpenTag casing.
Use supplied high-resolution files or SVG rather than enlarging a small PNG.

The vector adaptation and optional dimensional rendering are separate styles.
Use one consistently on a given product surface. The vector system is the
canonical source for all bundled platform and branding exports.

EXPORT CHECKS
PNG dimensions and transparency, SVG/XML structure, ICO/ICNS image frames,
manifest and asset-catalog file references, and safe-zone geometry are checked.
The assets have not been installed in your app project or tested on devices.
The iOS resource supplies the default static appearance; layered Icon Composer,
dark, and tinted Apple appearances are outside this package.
