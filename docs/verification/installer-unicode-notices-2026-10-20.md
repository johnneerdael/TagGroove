# Installer notice text preservation

Unmerged L76 preparation. The confirmed encoding_rs WHATWG notice contains
a copyright symbol; retaining it verbatim requires removing the old assumption
that all common notice text can be plain ASCII. This slice prepares that path;
it does not yet add the missing component materials or close the release audit.

The canonical UTF-8 `THIRD_PARTY_NOTICES.md` is unchanged. The generator
`scripts/installer-license.py` writes an ASCII RTF transport with escaped literal
braces/backslashes, paragraph/tab controls and signed UTF-16 Unicode escapes,
including surrogate pairs. `bundle.licenseFile` points to that generated RTF.
The notice test verifies the generated file is current, checks decoded text
against the complete source and exercises copyright, accents, CJK, a non-BMP
music symbol and control-looking literal text. It no longer treats a fixed
count of imported notices as proof of complete dependency coverage.
The test runner uses the existing `PYTHON`/platform interpreter selection;
an explicit LF checkout rule keeps generated byte comparisons portable.

[Tauri's pinned CLI 2.12.3 NSIS bundler](https://github.com/tauri-apps/tauri/blob/tauri-cli-v2.12.3/crates/tauri-bundler/src/bundle/windows/nsis/mod.rs)
copies license bytes with a UTF-8 BOM. [NSIS LicenseData](https://nsis.sourceforge.io/Reference/LicenseData)
accepts RTF; its [compiler source](https://github.com/NSIS-Dev/nsis/blob/master/Source/script.cpp)
reads past the BOM before detecting the RTF header. A minimal local NSIS
Unicode fixture uses the same BOM-prefixed RTF payload and compiles successfully.
The fixture contains no application and was not executed. This is a compiler
admission check, not Windows license-page rendering proof.

Three focused installer-notice tests pass. An independent macOS RTF text reader
(`textutil`) returns the exact complete canonical notice and the exact separate
Unicode/control-looking fixture. Diff checks and final read-only review pass.
No app/native UI was launched,
and no full application build or CI run was triggered. Full dependency notice
inventory, package delivery and Windows/native acceptance remain L76 work;
this preparation supplies no legal compliance or release completion claim.
