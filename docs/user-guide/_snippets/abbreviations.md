*[ID3]: The tag format used by most MP3 files (ID3v1 at the end of the file, ID3v2 at the start)
*[ID3v1]: The old, fixed-size MP3 tag at the end of the file: 30 characters per field, no covers
*[ID3v2]: The modern MP3 tag at the start of the file, in versions 2.3 and 2.4
*[APE]: APEv2 tags, used by Monkey's Audio, Musepack and WavPack files
*[APEv2]: The tag format of Monkey's Audio, Musepack and WavPack files
*[MP4]: The container of .m4a, .m4b and .mp4 files; its tags are stored in "atoms"
*[ASF]: Advanced Systems Format, the container of Windows Media (.wma) files
*[CDDB]: Compact Disc Database, the protocol of freedb and gnudb
*[MiB]: Mebibyte: 1,048,576 bytes
*[KiB]: Kibibyte: 1,024 bytes
*[BOM]: Byte order mark: a few invisible bytes at the start of a text file that identify its encoding
*[UTF-8]: The most common Unicode text encoding
*[CSV]: Comma-separated values, a plain-text table that spreadsheets open
*[regex]: Regular expression: a pattern that describes a shape of text
