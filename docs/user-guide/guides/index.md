# Guides

Choose a guide when you know the result you want and need the steps to get
there. Each guide covers a part of everyday editing, including what changes,
when it is written and what to check afterward.

If selecting files or saving edits is unfamiliar, complete
[Your first tagging session](../learn/first-tagging-session.md) first. If you
already have a very specific cleanup problem, the
[Cookbook](../cookbook/index.md) offers smaller recipes.

## Select, inspect and edit

| Your goal | Guide |
| --- | --- |
| Select the right rows, sort them or edit a cell | [The file list](file-list.md) |
| Edit common fields across one file or a selection | [The tag panel](tag-panel.md) |
| Inspect less common fields or separate values | [Extended tags](extended-tags.md) |
| Add, inspect, replace or remove artwork | [Working with covers](covers.md) |
| Keep only rows that satisfy a condition in view | [Filtering the file list](filter.md) |
| Find occurrences and navigate results | [Find](find.md) |
| Transfer metadata between files | [Cut, copy and paste tags](copy-paste-tags.md) |

A filter changes which rows you see; it does not delete the other files.
Check the actual selection before editing or applying a batch operation.
Hiding a field or column similarly does not remove its stored metadata.

## Manage files and recover changes

| Your goal | Guide |
| --- | --- |
| Copy, move, send to trash or permanently delete audio files | [File operations](file-operations.md) |
| Keep associated lyric or karaoke files with supported file operations | [Associated lyrics and karaoke](associated-files.md) |
| Deliberately remove tags or tag types | [Removing tags](remove-tags.md) |
| Inspect and replay a recorded operation | [Undo and history](undo-history.md) |

Read [Editing, saving and undo](../getting-started/editing-and-saving.md)
before mixing these operations. Typing in the tag panel produces pending
edits, while applied converters, source imports and actions have their own
write boundaries. A recorded desktop Undo step belongs to the current
session; keep normal backups for recovery beyond it.

## Organize a larger collection

| Your goal | Guide |
| --- | --- |
| Reuse a cached view of configured music folders | [Library](library.md) |
| Understand chapter and cue-sheet rows | [Chapters and cue sheets as rows](chapters.md) |
| Use format-specific cleanup utilities | [Utilities](utilities.md) |
| Write or load playlists and cue sheets | [Playlists and cue sheets](playlists.md) |
| Read supported local XML playlists | [Local XML playlists](xml-playlists.md) |

The Library is a way to browse known files, not an independent music backup.
Chapter rows and provider documents also have operation-specific limits.
Follow the guide for that kind of row before treating it as an ordinary
desktop file.

## Make the workspace fit your routine

Start with [Customize TagGroove](../customize/index.md). It helps choose
between columns, tag-panel fields, suggested values, toolbars, external tools
and language settings. Save the current configuration before a large change
so there is a deliberate return point.

## When the task needs a formula or a batch

Use [Automate](../automate/index.md) for naming converters, actions, online
tag sources and export. A **format string** builds text; a **regular
expression** recognizes a text pattern; an **action** applies a chosen
operation. Their reference pages explain exact syntax, while the
[Learn section](../learn/index.md) teaches them from the beginning.
