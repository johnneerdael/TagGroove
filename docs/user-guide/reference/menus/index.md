# Menu reference

Use menus to discover commands and check what a shortcut will do in the
current context. A disabled item usually needs selected files, saved pending
edits, a supported file type or an available platform capability. These pages
follow the current desktop interface's English labels.

| Menu | Use it for |
| --- | --- |
| [File](file.md) | Save/reload tags, load folders or playlists, export reports and manage configuration |
| [Edit](edit.md) | Undo, tag clipboard, selection, file transfers and deletion |
| [View](view.md) | Filter, tag panel, columns, sorting, toolbars and layout |
| [Convert](convert.md) | Generate names or fields from existing data, import text and number tracks |
| [Actions](actions.md) | Saved groups, Quick settings and explicit direct runs |
| [Tag Sources](tag-sources.md) | Search metadata providers, review results and manage installed sources |

## Choose the scope first

Some commands use **selected files**; others explicitly use **all files**.
**Playlist (all files)** and **Playlist (selected files)** are different
commands. A filter changes the visible list, and selection commands work with
that view. Check the selection before writing or deleting.

A preview calculates a proposed result. Pending edits wait for **Save tags**.
Other commands write when their own **Apply** or **Export** button is chosen.
The linked workflow page identifies that command's write step.

## Other menus

[Context and helper menus](context-menus.md) explain the commands offered by
a file row, tag panel, cover window, Extended tags field and helper input.
The helper button beside a supported format-string or field-name input opens
a helper menu. **Control+Space** opens the focused input's supported helper.
These helpers insert syntax or remembered values; they do not apply an action
by themselves.

The tag panel's options menu controls visible fields, custom values and panel
configuration. A dialog such as Actions or source review has its own
selection, enabled-state and keyboard rules. See [keyboard shortcuts](../keyboard-shortcuts.md)
before reusing an F-key in another area.

## Platform and version differences

File-manager labels become **Open in Finder**, **Open in Explorer** or
**Open in file manager**. Command replaces many Ctrl shortcuts on a Mac, with
physical Control exceptions in the keyboard reference. Mobile/provider-document
workflows can lack directory picking or native file operations.

An entry documented for another application, such as a separate **Exit** item
or a different playlist-generator shortcut, is not automatically part of
TagGroove. Use the current visible labels and linked workflow instructions.
