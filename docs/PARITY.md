# Mp3tag 3.36.1 parity ledger

The goal remains active. The application is a partial reconstruction; passing its current tests does not establish exact feature or performance parity.

Reference target: `../Mp3tag.exe`, SHA-256 `484794eec4e2b9a649d04eaab63b4cc73127ceb48a9e46075ea488c0e1eac911`. Static resource evidence inventories 1,110 resources, including 88 dialogs and three menus. The release includes 43 language files. `evidence/feature-inventory.json` retains every English language key and raw menu command ID. Many menu labels are numeric placeholders populated at runtime; their runtime label mapping remains to be recovered.

The [remaining-gaps register](research/remaining-gaps.md) lists every partial or missing item found by a code audit of `main` at `d220ad9` against all menu, keyboard, scripting, placeholder, filter, action, converter, export, options, source and format pages, with impact and size. Its "Closed after this audit" sections record batches 5 to 7, and its counts were recounted for `main` at `9633497` plus the UI translations of PR #17 (`feat/core-parity`, 2026-10-15). The rows below summarise it. Unless a row says otherwise, evidence is unit tests plus a native UI suite that CI runs headless on Linux, macOS and Windows; no row has differential evidence against the original program.
